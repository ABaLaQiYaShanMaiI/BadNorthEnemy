# 优化日志（2026-08-25）—— 兵种配合致命化 + 黑矛兵技能丝滑化

> 依据：对照 BadNorthDatabase 原版 `PikeChargeComponent.cs` / `Swordsman.cs` / `Archery.cs` 与
> 维京长矛 `VikingSpearBrain.cs`（Approach/Brace/Stab 状态机）的逐条结论，对 `BadNorthMixedSquad1.0`
> 进行一轮"丝滑 + 致命"专项优化。构建 0 警告 0 错误（Release，--no-incremental 强制重建验证）。

## 一、黑矛兵技能释放丝滑化（SpearChargeComponent.cs）

| 项 | 改动 | 原值 → 新值 | 依据 |
|---|---|---|---|
| 1 | **触发扫描节拍** | 0.25s → 0.1s；冷却结束 `_actScanTimer=0` 立即重扫 | 原版技能触发由 Brain 节拍驱动，扫描太慢 = 指令不跟手 |
| 2 | **静态注册表** 替换 `Resources.FindObjectsOfTypeAll<SpearChargeComponent>()`（`IsLockedByOthers` / `FindNearestEnemy` 两处） | OnEnable/OnDisable 维护 `List<SpearChargeComponent>`，含 `_agent==null`（未 Setup 模板副本）守卫 | Unity Mono 的 FindObjectsOfTypeAll 每次全场景遍历（含预制体副本），是 10Hz 扫描的卡顿源 |
| 3 | **冲锋发射点对齐视觉位** | `navPos.wPos` → `transform.position`（发射瞬间把 navPos 同步到视觉位） | navPos 因动画追赶可领先 transform ≤1m，用 navPos 当起点 = 冲锋第一帧"瞬移跳" |
| 4 | **发射瞬间重锁方向** | 起手结束用"目标最新位置 − 视觉起点"重锁 `_chargeDirection` | 0.5s 前摇内目标位移后，旧方向导致冲锋线对不准（仍是非追踪，只在发射时刻锁线） |
| 5 | **冲锋加速曲线** | 线性满速 → `SmoothStep(0→1, 0.12s)` 加速，`_phaseTimer = 时长 + 0.12s` | 静止→满速跳变 = 起手瞬移感；加速曲线有爆发感且不跳 |
| 6 | **LateUpdate 平滑逼近** | 每帧 teleport `transform=navPos` → `MoveTowards(≤速度×dt×1.25)`，偏差<3cm 让 Body 自己追赶，偏差大按 0.25 比例拉近 | teleport 与 Body 插值打架 = 视觉抽动；平滑逼近保动画连贯 |
| 7 | **起手转向提速** | 720°/s → 1080°/s | 背对目标时原 720 会把 0.5s 前摇大半耗在"转圈"上 |

## 二、兵种配合致命化

### 1. 盾后架矛（叠刺墙，TacticalFormation.cs + Plugin.cs + SpearChargeComponent.cs）

- **问题**：混编中列矛兵被 `PinSpearsWhenIdle` 钉死，Swordsman 大脑"ready→attack"的 order 门控
  （`dot(enemyDir, orderDir)>0`）在钉位下大概率不满足 → 盾线接敌期矛兵只等冲锋、不刺击 = 纯浪费 DPS。
- **解法**：`CommandLanceStabs()`（接敌阶段每帧执行）直接启动 `Swordsman.attack` 状态，走与
  `Plugin.SwordsmanAttackPrefix` 完全同款的链路（attack.SetActive + target + swingSound + MaybeParry +
  `NotifyMeleeAttackStart`），`SwordsmanAttackUpdatePrefix` 接管刺击周期并自动连刺。
  - 保守守卫：非冲阵中 / 未在攻击 / aliveAndGrounded / 非滑动（眩晕僵硬期不刺）/ 登岛 / 距离校验 /
    **体力 ≥0.45**（尊重原版体力经济：体力不足一次刺击（cost 0.5）不强行出手，保持"两刺一缓"的攻速节奏）。
  - 配套：`Swordsman.range` 阵型内 +`FormationLanceReach(0.35m)`（Plugin.SwordsmanRangePostfix）、
    `TestHit` 命中距离同步 +0.35m、矛刺视觉刺出距离 0.45→0.70m（FormationThrustDistance）。
  - 效果：盾墙顶住仇恨时，中列矛兵矛尖越过盾线持续叠刺 ≈ 双倍前排输出；敌破盾近身时矛兵同时自保。
- **可回退**：删 `WaveEngageUpdate` 里的 `CommandLanceStabs();` 一行即可恢复旧行为。

### 2. 阵型穿透目标（SpearChargeComponent.cs + TacticalFormation.cs）

- **问题**：冲阵号令时矛兵选"最近的敌人"→ 冲锋线只穿前排盾兵（被格挡 ×0.2），打不到后排弓手/脆皮。
- **解法**：`FindDeepestEnemyInCone()`——收到号令后优先选**正前方锥形区（±33°，基准=阵型朝向）内最远**
  敌人（>0.8m，地形通畅），冲锋线贯穿整条敌阵：途经前排（盾牌背向不格挡 = 背刺）→ 终点爆发打后排。
  无锥形区目标回退大脑目标/就近扫描；协同防重与地形兜底逻辑保持不变。
- 新增 `TacticalFormation.GetFormationFacing(Agent)` 静态查询（阵型朝向 = `_facing`，每帧指向最近敌）。

## 三、关键日志关键词（游戏内验证用）

- `[阵型] 盾后架矛: 中列矛兵刺击 ...（叠刺输出）`——每 5s 节流，确认盾后刺击在跑。
- `[Charge] 阵型穿透目标=... 距离=...m（锥形区最远=贯穿敌阵，终点爆发打后排）`——确认穿透选目标。
- `[Charge] 冲锋起点 pos=...` 起点 = 视觉位（不再是 navPos 领先值）→ 无"起手跳"。
- `[Charge] 冲刺中 ... lag=...`——lag 应显著变小（LateUpdate 平滑逼近）。
