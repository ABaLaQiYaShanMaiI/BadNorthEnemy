# 黑矛兵 → 混编战术小队 转型计划

> 状态：规划阶段（2026-08-18）
> 背景：用户对比维京长矛项目后提出转型——不再只有"黑矛兵"，而是**一船三兵种混编战术小队**：
> 剑盾兵稳住阵脚、长矛兵冲锋回撤后在盾后刺击、弓箭手后排射击；全队仍是**一个小队**，遇到敌人**排起队列**。
> 本文档是可行性结论 + 架构设计 + 里程碑路径，落地时按里程碑推进并同步开发日志。

---

## 一、目标行为拆解（用户需求 → 行为项）

| # | 需求 | 行为拆解 |
|---|---|---|
| 1 | 生成长矛兵的同时生成剑盾兵和弓箭手 | 同一艘船/同一个 Squad 内混编三种兵种（不再是单兵种 Squad） |
| 2 | 混搭在一艘船上 | 三者随同一 VikingReference/Squad 登岛，同一锚点 |
| 3 | 剑盾兵稳住阵脚 | 盾兵前排列，Swordsman 接敌 + Shield 格挡 |
| 4 | 长矛兵冲刺后回退至阵后 | 冲锋 → 回退（已有）→ 回**中列**阵位 |
| 5 | 在保护下刺击敌人 | 站在盾后一列用长矛刺击（射程 0.69m ≫ 剑 0.118m，够得着盾前敌） |
| 6 | 弓箭手在后面射击 | 弓手钉**后列**，敌人进射程才射，逼近则后退 |
| 7 | 仍旧是小队 | 一个 Squad 对象 = 一艘船 = 一个小队，共生死/共撤离 |
| 8 | 遇到敌人则排起队列 | 上岛 → 抵阵位 → 对敌方向**分层列队**（盾/矛/弓三列）→ 敌人进范围才交战 |

## 三、需要新建的三块（真正的活）

### 块 1：混编生成（骨架）
- 继承原版 `SquadCoordinator`，实现"按比例分配角色"：每个生成的 agent 按序取角色（盾:矛:弓 可配，如 4:3:2）。
- Patch `Squad.CreateAgent`：当小队是"黑矛混编"类型时，按角色换 prefab（盾→SwordShield 基底 / 矛→黑矛兵剥离模板 / 弓→Archer 模板）。
- 需要一个新的 VikingReference（或改造现有 Viking_BlackSpearman 的 vikingClone），其 Squad 由混编生成。

### 块 2：战术分层站位（核心，新组件）
- 原版敌方维京**不排队列**（SquadFormation 只挂在 EnglishSquad.cs:230 / NavSpotFormationSquad）。
- 新建 `MixedSquadCoordinator`（或 `TacticalFormation` 组件）：
  - 以小队锚点为中心、**对敌方向**为前方，分配三层格：前排=盾、中列=矛、后列=弓；
  - 每帧把各 agent 钉在相对锚点的格位（复用 SquadFormation.Get(index) 网格数学 + 本项目 TrackSpearToHand 的每帧同步思路）；
  - 面对方向：全队朝敌方威胁方向（盾朝前，矛/弓保持同向）。
- 格位随存活数动态收缩（死人收拢阵型）。

### 块 3：角色战术触发 + 防御状态机（工作量最大）
- **全队状态机**（Squad 级）：登岛 → **抵阵位**（防御模式，敌人进范围前不交战）→ 敌人进范围 → 交战。
  - ⚠️ 这与原版"维京直冲建筑/玩家"行为差异最大，是全新行为，需要独立状态机。
- **长矛**：已有冲锋触发；新增"冲锋回退后回**中列**，再刺击（射程 0.69m 穿盾线够敌）"。
- **弓手**：钉后列；敌人进射程才射；敌人逼近则后移（约束 Archer 不贴脸）。
- **盾兵**：前排列，原版 Swordsman 接敌 + 盾牌格挡，维持阵线不突进过深。

## 四、风险与取舍

1. **"排起队列等敌"是全新行为**：原版敌人没有防御阵型概念，Squad 级防御状态机需自建，是最大工作量与最大不确定性。
2. **Squad.prefab 单兵种假设**：Squad 的命名/补充/UI 路径假设单 prefab；混编需容忍（敌人侧影响可控，不涉及玩家补给）。
3. **弓手前排化**：原版弓手会贴脸射击，需加"远离前排"约束，否则阵型失效。
4. **混编的平衡**：三兵种同队 = 总战力提升，需调 bounty/配额/血量倍率，避免碾压。
5. **冲锋与阵型的冲突**：长矛冲锋会脱离阵线（穿透+回退 0.6m），回退落点必须精确回到中列，否则打乱阵型——冲锋触发/落点要跟格位联动。

## 五、里程碑路径（增量，每步可玩可验证）

### 里程碑 1：盾+矛混编（最小可玩）
- Patch CreateAgent：同船生成 盾:矛（先不做弓）。
- 验证：一船两兵种、同小队；盾前矛后（简单站位：矛跟盾，不严格队列）；长矛冲锋→回退→盾后刺击。

### 里程碑 2：分层站位 + 抵阵等敌
- 新建 TacticalFormation 组件：对敌方向三层格 + 每帧钉位 + 死亡收拢。
- 全队防御状态机：上岛→抵阵位→进范围交战。
- 验证：遇敌排起三列（此时弓可先由盾/矛占列）。

### 里程碑 3：弓手后排 + 完整战术
- 生成加弓手；弓手钉后列、射程触发、逼近后退。
- 完整数值：比例/血量倍率/bounty 平衡。

## 六、验证方式

- 每里程碑构建部署后进游戏实测；日志按现有关键词分类（[混编]/[阵型]/[冲锋]）。
- 关键观察点：登岛后是否抵阵列队、盾线是否顶住、长矛冲锋回退是否回中列、弓手是否保持后列射击。
- 阵型像素验证可复用 [像素采样]/[头部统计] 类探针思路（如需）。
