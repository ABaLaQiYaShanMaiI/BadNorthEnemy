## 1. 待解决困惑（按优先级）

### 🔴 P0-1：冲锋触发不可靠（黑矛兵"走路到阵前"）

**现象**：黑矛兵有时不冲锋，而是普通走路接近我方阵前；矛伸进阵营但没有冲锋伤害。
**可能原因**：
- 协同防重（`FindNearestEnemy`）把所有 6m 内目标标记为"已被其他黑矛兵锁定"→ 本黑矛兵放弃冲锋，转普通追击
- `TryTriggerCharge` 条件拦截：`dangerous` / `navPos.onMain` / `aliveAndGrounded`
- 冲锋距离短（敌人贴脸时冲锋 1-2m，视觉像走路）
**诊断日志（已加，待测）**：
```
[Charge] 触发拦截: alive=... dangerous=... onMain=...        ← 哪个条件卡住
[Charge] FindNearestEnemy: 探测collider=N 已锁定目标=K → 无可用目标   ← 协同防重锁光
```
**修复候选**：
- 若"已锁定目标=K"过多 → 协同防重降级：允许 2 个黑矛兵锁同一目标，或优先未锁定的目标但**不放弃**（无可用目标时选最近的，即使被锁）
- 若 dangerous=false → 检查 Swordsman 状态机与 chargeState 互斥

### 🔴 P0-2：冲锋命中率低（矛尖进入阵营未命中）

**现象**：矛尖扫过我方单位但没有倒地/击飞/受伤。
**可能原因**：
- 命中判定用 `navPos.wPos + 冲锋方向×矛长0.6m`，但冲锋时 `transform` 滞后 navPos（lag 可达 1.1m），矛尖位置与视觉不符
- 目标横移/后退躲闪（锁定格不追踪）→ 矛尖扫过空位
- 命中半径 0.4m 仍可能偏小
**诊断日志（已加，待测）**：
```
[Charge] 命中诊断: 矛尖=(x,y,z) ... collider=N
[Charge]   候选 xxx dist=Xm → 命中!/跳过原因
[Charge] 命中诊断: 矛尖=... 半径=0.4m 内无任何collider     ← 矛尖没对准
```
**修复候选**：
- 若"内无任何collider" → 检查矛尖位置计算；考虑用 transform 视觉位置或加大矛长
- 若候选被"是维京友方(跳过)"过滤 → 检查 isViking 判定

### 🟡 P1-3：协同防重过度

**现象**：多个黑矛兵时，后面的黑矛兵经常找不到目标（目标全被锁定）→ 不冲锋。
**诊断**：`FindNearestEnemy: 已锁定目标=K`（K 接近探测到的目标总数）。
**修复候选**：
- 降级为"软防重"：优先未锁定目标，但若全部锁定则选最近的（允许重叠，但少）
- 或只在同波次/近距离黑矛兵间防重

### 🟡 P1-4：冲锋视觉冲击感

**现象**：用户反馈"冲锋速度不快/冲击阵营效果不明显"（已调 5m/s + 穿透 1.5m，待验证）。
**待验证**：穿透冲锋是否明显（黑矛兵冲进敌阵、穿过）。
**可调**：`ChargeSpeed` 5→6，`ChargeOvershoot` 1.5→2.5。

### 🟡 P1-5：免疫攻击边界

**现象**：冲锋+后退全程免疫攻击（attack.ignore），黑矛兵"无敌冲进无敌退走"。
**待确认**：是否保留全程免疫，或只冲锋阶段免疫（后退阶段可被打）。
**风险**：全程免疫 + 后退 0.6m + 冷却，黑矛兵可能显得"无敌且反复试探"。

### 🟢 P2-6：剑的视觉残留

**现象**：黑矛兵身体动画帧（Swordsman0001~0098）里画死持剑姿势，无法运行时去除。
**根因**（多轮日志实证）：`sprite2 = PartTex_Median_BlurAlpha` 是**身体贴图**（带 alpha 的身体轮廓遮罩），透明化任何区域都会让身体消失；剑是身体帧像素。
**结论**：放弃去剑，接受剑影，长矛主导视觉。
**可选**：换基底 `Viking_Twohanded`（但自带技能组件，已放弃）。
